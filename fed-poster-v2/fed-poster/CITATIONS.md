# 📚 Citations & Attribution

If you use, fork, build upon, or reference Fed-Poster in academic work, products, or projects, please cite it. Citing open-source projects helps sustain them and gives proper credit to contributors.

---

## 📦 Recommended Citation (BibTeX)

```bibtex
@software{FedPoster,
  title        = {Fed-Poster: Open-Source Multi-Channel Publishing Dashboard},
  author       = {{FED-OS} and {Fed-Poster contributors}},
  year         = {2026},
  url          = {https://github.com/FED-OS/Fed-Poster},
  license      = {MIT},
  version      = {2.0.0}
}
```

---

## 📝 Plain-Text Citation

> FED-OS and Fed-Poster contributors. (2026). *Fed-Poster: Open-Source Multi-Channel Publishing Dashboard* [Computer software]. https://github.com/FED-OS/Fed-Poster . Licensed under the MIT License.

---

## 🌐 Cite a Specific Version

To cite a specific release, replace `version` and add a `note` with the release tag:

```bibtex
@software{FedPoster200,
  title        = {Fed-Poster: Open-Source Multi-Channel Publishing Dashboard},
  author       = {{FED-OS} and {Fed-Poster contributors}},
  year         = {2026},
  url          = {https://github.com/FED-OS/Fed-Poster},
  license      = {MIT},
  version      = {2.0.0},
  note         = {Release v2.0.0, DOI 10.xxxx/zenodo.xxxxxxxx}
}
```

> 🆔 When a Zenodo DOI is minted for a release, it will be listed here. Until then, cite the GitHub release tag directly.

---

## 🧩 Citing Specific Features or ADRs

If your work builds on a specific architectural decision, cite the relevant ADR from [ADR.md](ADR.md):

```bibtex
@misc{FedPosterADR0007,
  author       = {{FED-OS}},
  title        = {{ADR-0007}: Adding a New Platform Adapter},
  year         = {2026},
  howpublished = {Fed-Poster Architecture Decision Records},
  url          = {https://github.com/FED-OS/Fed-Poster/blob/main/ADR.md#adr-0007-adding-a-new-platform-adapter}
}
```
